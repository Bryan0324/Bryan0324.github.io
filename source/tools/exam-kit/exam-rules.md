# 考場公告與準備方式

來源：使用者於2026-11-10在對話提供的招生小組公告文字。此日期是本包收到與更新的日期；原文未附發布日期，本包未另行查核公告網址。

## 對本包的直接影響

| 已明確的規則 | 準備方式 |
|---|---|
| 本地模型、名稱不公開、網頁聊天 | 不再針對Gemma或某一模型調整；用固定小任務校準實際表現 |
| 無檔案上傳，單次貼文／對話長度有限 | 短提示卡＋必要程式片段；人手收集、執行、回報；長對話用交接卡重開 |
| 可連網、登入個人帳號、開自己的雲端筆記 | 考前整理可搜尋／複製的靜態筆記與官方文件索引 |
| 外部LLM、AI Agent、Copilot等不能用 | 旗艦模型只在考前製作／審查資料；考場使用提供的模型 |
| 搜尋引擎AI摘要不能用 | 優先官方直接連結，查詢時使用普通網頁結果並關閉／避開AI摘要 |
| Gmail、LINE、Discord等通訊服務禁止，不能聯絡他人或傳資料 | 不把信箱當筆記入口；使用自己的靜態筆記，現場工作紀錄留在考場電腦 |
| 可以帶紙本筆記和書籍 | 印分流表、關鍵指令、常用規則、筆記入口與官方網址 |
| 考場不提供離線文件 | 自備紙本重點，完整手冊用考場電腦上網查 |
| 禁止個人裝置，使用考場電腦 | 準備不依賴手機／自備電腦才能開啟的筆記入口 |
| OS／開發環境當天公布，版本不影響作答 | 先讀當天啟動說明，沿用提供的工具；不用預先押定Jazzy Docker或歷屆PlatformIO |

仍未知：實際貼上／對話上限、模型能力與回應速度、當天OS／工具。不能由「消費級硬體可部署」推算具體模型大小、context長度或解題水準。

Skills在這裡是預寫的靜態任務筆記；考場用法是人工摘取文字貼入提供的聊天介面，不是啟動另一個AI工具。

## 使用者提供的公告原文

```text
各位同學好：

最近陸續收到考生來信詢問上機考試規則，以下統一說明。

一、考場提供的 AI 服務
模型：考場提供的是可以部署在消費級硬體上的大語言模型，不公開模型名稱。
部署方式：模型部署在考場本地，考生不用支付任何使用費用。
使用介面：網頁聊天介面。考場不提供 Copilot 或其他 AI 程式輔助工具。
使用限制：不提供檔案上傳功能。對話長度和一次貼上的程式碼長度設有合理範圍內的限制。
二、網路與線上服務
考試期間考場電腦可以連上網路。考場電腦能連上的線上服務，同學都可以自由使用，包含登入個人帳號、開啟自己存在雲端硬碟的筆記。不過，考場提供的模型以外的大語言模型服務一律不能使用，例如 ChatGPT、Claude、Gemini 等聊天機器人、AI Agent 類工具，以及 GitHub Copilot 等 AI 程式輔助工具。搜尋引擎的 AI 摘要也不能使用。考試期間也禁止使用任何通訊軟體或服務，例如 Gmail、LINE、Discord，不得和他人聯絡或傳遞資料。

三、參考資料
同學可以帶紙本筆記和書籍進考場。考場不提供離線文件，需要查 RP2350 datasheet、Pico SDK、ROS 2 等文件的話，請用考場電腦上網查詢。

四、考場設備
考試一律使用考場提供的電腦，不用自備筆電，考試期間也禁止使用任何個人裝置。作業系統和開發環境的詳細資訊會在考試當天公布，環境版本不會影響作答。

如果還有其他問題，歡迎來信詢問。

祝 準備順利，考試成功！

國立成功大學 資訊工程學系
特殊選才小組
```

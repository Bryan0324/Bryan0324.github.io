# exam-kit 實用性檢查

檢查日期：2026-11-11。需求依 [考場公告](exam-rules)、現存 demo 與歷屆 README；程式結果見 [驗證紀錄](validation)。

## 結論

**可用作考前練習與考場查閱／貼給指定聊天模型的輔助包；完整考場流程仍需實測。**

它已涵蓋「找問題→選短卡→提供必要資料→做最小修改→執行驗收→換題交接」。不熟 ROS、PIO、DMA 時有查詢順序與模板，適合已懂 C 位元運算、需要操作提示的使用者。

## 需求對照

| 需求 | 判定 | 依據／使用限制 |
|---|---|---|
| 只能用考場網頁模型、無上傳 | 符合 | 所有短卡由人貼內容、執行命令、回報；不需要 agent 或檔案工具 |
| 貼文／對話有限制 | 符合設計，待現場適配 | S0～S8 短卡、縮小片段、交接模板；上限未知，沒有保證任意程式都貼得下 |
| 快速選對領域 | 可用 | 主頁分流表、短卡直達、詳解與範例；S 卡在各技能頁首，查找用 Ctrl-F／索引，全站文章搜尋未收錄工具頁 |
| demo／歷屆可遷移的題型 | 主要路徑已涵蓋 | ROS、併發、搬運、PIO、ISA、排序與 hash；題目規格優先 |
| 可以直接複製程式 | 有條件 | 主機範例可驗收；ROS 需現場套件；micro-ROS 是有佔位欄位的接線片段；Pico 需 SDK／板子 |
| 手冊查詢 | 可用導覽 | 官方入口、搜尋詞與備援 header；不是完整離線手冊，網站可達性仍取決於現場 |
| 遇到錯誤能自救 | 可用流程 | 第一個錯誤、A/B 觀察、最小案例、兩次無效重新定位、交接與回退 |
| 真實得分／效能 | 尚未驗證 | 缺正式 judge、題目介面、現場模型與硬體測試；主機 PASS 不能替代 |
| 雲端與紙本可取用 | 本機可檢查，正式入口待驗收 | 本次未發布遠端；需無個人裝置也能開啟的網址與紙本入口 |

## 本次發現並修正

1. README 的舊 cheatsheet、`SKILL`、X1 `.txt` 入口與 demo 路徑失效，共 13 個來源連結問題。
2. 來源檔存在不等於網站可開：Hexo 產生 `.html`，原本多數無副檔名連結會失效。改用實際網站路徑並檢查生成頁與錨點。
3. X1／交接卡連反、表格欄數不一致；prompts 頁缺 S0～S8 導覽。補上總索引與每張短卡的直達標題。
4. 歷屆 README 的水平線被當成 front matter，建置日誌報錯卻仍 exit 0。補上明確 metadata，使該頁能正常產生。
5. 建置檔搜尋誤寫 `CMakeLists`，已改成 `CMakeLists.txt`；練習路徑、卡片位置與網站閱讀方式一併校正。
6. 來源狀態更新：本包目前未附舊紀錄引用的 PDF、歷屆圖片、完整 MNIST 模型與韌體；已標示，不當成現有可執行材料。

## 使用前仍需完成

| 優先 | 實際動作 | 通過條件 |

| 1 | 發布網站後，以不依賴手機登入的方式開正式入口 | 主頁→S2短卡→模板→官方文件皆可開；短卡可完整複製 |
| 2 | 在可用 Docker／ROS 環境跑 [ROS 模板](examples/ros2/README) | 21、0、-5 分別回 42、0、-10；能解釋三個終端角色 |

| 4 | 要用板端模板時，先沿當天骨架建置、燒錄與收送 | Pico PIO 連續不同 word、DMA 第二輪／sentinel；micro-ROS ID 與最大長度正確 |
| 5 | 填紙本入口並做列印預覽；當天用第一個小任務觀察模型 | 不靠個人裝置取資料；模型給得出最小修改與可執行驗收 |

目前本機 Docker CLI 存在，但 `docker info` 無法連到 Docker Desktop Linux engine，因此本次無 ROS 端到端結果。先啟動既有 Docker Desktop，再照 ROS 模板流程驗收即可。

網站已完成本機 build、生成連結／錨點、27 頁 HTTP 200 與 11 個提示卡區塊文字比對。瀏覽器工具因註冊失效無法啟動，所以畫面、剪貼簿按鈕與列印預覽仍需手動驗收；這些不以 HTML 通過代替。

**最值得再投入的準備是上述實操，不是再增加提示詞數量。** 若只能再花 30 分鐘，先驗正式網址與複製，再跑 ROS 三筆與一次交接；PIO／DMA 在有板子與工具鏈時優先補實機紀錄。

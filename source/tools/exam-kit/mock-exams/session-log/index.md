## 協作品質另記，不加到試卷分數

| 項目 | 0 分 | 1 分 |
|---|---|---|
| 證據 | 無依據猜原因 | 引用實際規格／輸出或索取必要缺漏 |
| 最小修改 | 重寫無關內容或改唯讀介面 | 只改本輪必要部分 |
| 可驗收 | 只說「應該可以」 | 提供命令、預期結果與失敗後要回報的資料 |
| 誠實性 | 虛構 API／執行結果 | 區分推導、主機測試與實機驗證 |
| 交接 | 忘記限制或重做已排除方案 | 保留目前程式、規格與已驗證事實 |

同時記錄 0～5 分、總耗時與往返輪數。題目答對但操作很慢，與答錯卻很快，是不同問題；二刷、看過解答或換提示方式都要註記。
